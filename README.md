# Anniversary Surprise ❤️

A cinematic, interactive anniversary website designed for GitHub Pages.

## Add your media

Replace these files:

- `assets/photos/` — add your photos
- `assets/music/anniversary.mp3` — your background music
- `assets/video/surprise.mp4` — your final surprise video

The current website intentionally uses elegant placeholders so you can personalize it later.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will give you the public website URL.

## Customize names and dates

The main text is in `index.html`. Search for the placeholder text and replace it with the couple's names, wedding year, dates, stories and captions.

## Recommended final media

For phones:
- Video: MP4 / H.264, 1080p
- Music: MP3
- Photos: JPG/WebP
- Keep the video reasonably compressed so GitHub Pages loads quickly.
