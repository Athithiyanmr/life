# Anniversary Surprise ❤️

A cinematic interactive anniversary experience for GitHub Pages.

## Media placeholders

Add your own files later:

- `assets/photos/first.jpg`
- `assets/photos/memory-01.jpg`
- `assets/photos/memory-02.jpg`
- `assets/photos/memory-03.jpg`
- `assets/music/anniversary.mp3`
- `assets/video/surprise.mp4`

The current interface is designed so the media can be added without rebuilding the page.

## Personalization

Edit the text in `index.html` to add names, wedding date, captions and personal memories.

## GitHub Pages

Repository: https://github.com/Athithiyanmr/life

Enable **Settings → Pages → Deploy from a branch → main → / (root)**.
